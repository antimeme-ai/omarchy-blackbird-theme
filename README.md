# omarchy-blackbird-theme

SR-71 Stratosphere Cockpit theme for [Omarchy](https://omarchy.org), calibrated to Blackbird's default Hero Flight Deck `synthwave` palette (`#0b0120` stratosphere sky, `#ff2fd0` rim magenta, `#05d9e8` Mach cyan, `#ff9a3c` afterburner amber).

## Install on Omarchy

```sh
omarchy theme install https://github.com/antimeme-ai/omarchy-blackbird-theme
omarchy theme set blackbird
```

## Palette

Ships a complete native 25-key Omarchy v4.0 `colors.toml` (`mode = "dark"`), `keyboard.rgb`, and a 1920x1080 Stratosphere SR-71 wallpaper under `backgrounds/`.
